# Forca Coletiva

Jogo da forca para **3 jogadores**, feito em **Python** para o terminal. Trabalho bimestral de Ambientes de Programação do 1º termo de Sistemas de Informação (Unoeste).

## Regras
- 3 jogadores e 3 rodadas; vence quem tiver mais pontos no final.
- A cada rodada, cada jogador escolhe um tema e uma palavra para os outros adivinharem.
- Cada jogador tem 3 vidas; cada erro custa uma vida.
- Cada jogador tem direito a um chute por palavra, mas perde todas as vidas se errar.
- Cada letra certa vale 1 ponto. Completar a palavra vale o número de letras que faltavam, mais 5.

## Como rodar
Com o Python 3 instalado:

```bash
python main.py
```

O jogo limpa a tela com o comando `cls`, por isso foi feito para o terminal do Windows.
